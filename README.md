# 🍽️ Recipe Book Web App

A full-stack web application that allows users to manage and explore recipes.  
Users can register, login, and create their own recipes connected to a secure backend API.

---

## 🚀 Features

- 🔐 User authentication (Login & Register)
- 🍲 Add, edit, delete recipes
- 📋 View all recipes
- 🔍 Search functionality
- 🎨 Clean and responsive UI
- 🔗 Connected with ASP.NET Core API

---

## 🛠️ Tech Stack

- JavaScript (or React if applicable)
- HTML5 & CSS3
- REST API integration
- Axios / Fetch API

---
